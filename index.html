How to Add This 3D Portal to EcoClasses.in

Good news! This single file is already pre-configured with your live domain (https://www.ecoclasses.in) and all 49 of your Economics labels. Every new post or MCQ worksheet you publish on Blogger automatically appears in this 3D panel.

Method 1: Create a Dedicated 3D Page on Blogger (2 Minutes)

  1. Open your Blogger Dashboard for ecoclasses.in and go to Pages → New Page.
  2. Title the page 3D Portal (your link will become ecoclasses.in/p/3d-portal.html).
  3. Switch the editor from Compose view to HTML view (top-left pencil icon).
  4. Paste the full code of this file inside, or host this HTML file on free GitHub Pages / Vercel and paste this responsive full-screen iframe snippet:
<!-- Paste inside a Blogger Page (HTML View) -->
<style>
  /* Hide standard Blogger header/sidebar on the 3D Page */
  body, html { margin: 0; padding: 0; overflow: hidden; }
  #ecoclasses-3d-frame {
    position: fixed; top: 0; left: 0;
    width: 100vw; height: 100vh;
    border: none; z-index: 999999;
  }
</style>
<iframe id="ecoclasses-3d-frame" src="YOUR_HOSTED_3D_PORTAL_URL" allow="microphone"></iframe>
